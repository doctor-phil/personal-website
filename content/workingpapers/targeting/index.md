<li><b>Abstract:</b></li>

   Institutions that shape public opinion often change intervention intensity more easily than whom they reach. We study a decision-maker who commits to one exposure rule and reuses it over time. This restriction is vacuous in one period but consequential dynamically, because the rule changes the path on which it will later be used. Under equal centrality, a reusable rule follows disagreement that persists rather than disagreement that is merely large today; when centrality differs, exposure also follows agents' leverage over future opinions. Near a symmetric benchmark, reuse dampens the tilt toward persistent disagreement because the same pattern remains in place after that disagreement has decayed. The value of retargeting depends on the same path: one fixed rule can perform nearly as well as unrestricted targeting when path weight is concentrated in a few directions and the two policies agree there. Using Yale climate opinions and Facebook social connectedness, we find that California has greater authority than Texas but nearly the same exposure, consistent with Texas's greater future persistence. The realized path is nearly one-dimensional, so one fixed rule captures nearly all attainable gains, yet reuse still reallocates exposure substantially across states. Thus reuse can materially change whom to target even when the value of subsequent retargeting is small.
</ul>
